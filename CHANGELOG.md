### Funcionalidades
- **WhatsAppClient**: Cliente de alto nível para interagir com WhatsApp
- **SeleniumDriver**: Driver de baixo nível para automação
- **CLI**: Interface de linha de comando
- **Exceções**: Sistema robusto de tratamento de erros
- **Sessão**: Persistência de sessão do Firefox
- **Mensagens**: Envio e recebimento de mensagens
- **Contatos**: Gerenciamento de dados de contatos
